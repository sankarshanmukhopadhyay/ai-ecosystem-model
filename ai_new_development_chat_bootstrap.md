We have developed a logical model of the overall AI ecosystem that we are managing within a GitHub repo. The model is defined by a schema using LinkML written in YAML, and a model instance written in YAML.

The model instance includes values for variables (such as canonical orders of magnitude of elements in the global economy) and is used to generate mermaid diagrams embedded in a Markdown document representing different perspectives from the model (e.g. Governance, Economic, Technical, and whole of model). Web pages are generated using Docusaurus.

The model was created to make sense of how the global AI ecosystem works so that better understanding is developed of how things work, why they work that way, and the consequences of decisions and individual, organisation, and government levels.
